# TMS9900

The baseline TMS9900 is a 16-bit, big-endian functional machine with 64 KiB of physical memory. Code starts at `0x1000`, data and the 32 by 32 RGB bitmap at `0x4000`, and the initial workspace at `0x8000`. R10 initially contains `0xff00` for the examples' software stack. Workspace registers are **actual RAM words addressed through WP**, not an independent register file. Byte operations on workspace registers access the high byte; changes made through the memory inspector are immediately visible as register changes. Native instruction fetch, extension words and fall-through addresses wrap at the 16-bit boundary.

Native support includes register, indirect, autoincrement, symbolic and indexed addressing; word/byte moves, addition, subtraction, compare, SOC/SZC; immediate arithmetic/logical operations; shifts and rotates; integer status and jumps; unsigned MPY/DIV with register-pair results; BL/B and the RT alias; LWPI/LIMI, STWP/STST; BLWP, XOP and RTWP native workspace context switching. The source operand is evaluated before the destination. Native word data accesses ignore address bit zero; instructions are word aligned. R0 is ordinary RAM but cannot be an indexed base. `@address` selects symbolic addressing.

XOP follows native vectors at `0x40 + 4*n`, saving WP, PC, ST in new workspace R13–R15 and the effective source address in new R11. XOP also sets ST.X. A zero XOP 15 vector instead selects the **THRAX educational monitor**, reserving that uninstalled vector as a simulator service. R0 selects 1 (print signed R1), 4 (print zero-terminated string at R1), 5 (read signed 16-bit integer into R1), 10 (exit), or 11 (print low byte of R1). A nonzero vector restores ordinary native XOP 15 execution. This is not a TI-99 ROM or TM990 monitor emulation.

IDLE stops execution because this initial machine has no interrupt source to wake it. The baseline excludes CRU devices/instructions, external interrupt delivery, peripheral and TI-99 memory maps, X instruction execution, extended later-family instructions, and cycle-accurate timing. Unsupported instructions produce diagnostics or faults. DIV overflow sets OV and leaves the dividend register pair unchanged as native hardware does.

The shared assembler accepts `.text`, `.data`, `.org`, `.byte`, `.word`/`DATA` (16 bits), `.long` (32 bits), `.ascii`, `.asciz`, `.space`, `.equ`, colon labels, expressions and `.include`. `>1234` denotes hexadecimal. Native opcode syntax is case insensitive. Comments start with `;` or `//`; traditional column-sensitive TI source layout is not implemented.

References: [TI TMS9900 Microprocessor Data Manual](https://bitsavers.org/components/ti/TMS9900/TMS_9900_Microprocessor_Data_Manual_May76.pdf) and [TI 9900 Family Systems Design, instruction-set chapter](https://manualzz.com/doc/19758365/texas-instruments-tms9900-family-instruction-set-user-manual).
