# DEC Alpha AXP

This is an Alpha teaching machine with exact 64-bit general registers and 1 MiB of little-endian physical RAM. Code starts at `0x1000`, data and the bitmap at `0x10000`, and `$30` (SP) initially points near the top of RAM. `$31` always reads zero, ignores instruction writes, and is not editable. ABI aliases (`v0`, `a0`, `ra`, `sp`, etc.) and `$0`–`$31` spellings are accepted.

Native instruction words cover LDA/LDAH, byte/word/longword/quadword loads and stores (including BWX byte/word instructions), unaligned quadword forms, longword/quadword arithmetic and multiplication, overflow-checking `/v` forms, signed and unsigned comparisons, conditional moves, shifts, low byte extraction/insertion/masking, ZAP/ZAPNOT, integer branches, BSR, JMP/JSR/RET, and memory barriers. `mov`, `clr`, `nop`, `not`, `negl` and `negq` are conventional aliases emitting native instructions. Operate literals are unsigned eight-bit values; negative constants use LDA or a register. There is no invented integer divide instruction.

64-bit register values, quadword memory transfers and their reversible history values remain exact beyond JavaScript Number precision. Longword operations and LDL sign extend to 64 bits. Native calls put the return address in the encoded destination register; recursive examples explicitly save it on the stack.

`call_pal 0` halts. Real `call_pal 0x83` (callsys) is connected to a **THRAX educational ABI**, not an emulation of an operating system's syscall table. `$0` selects 1 (print signed 64-bit `$16`), 4 (print zero-terminated string at `$16`), 5 (read signed 32-bit integer, sign extended into `$0`), 10 (exit), or 11 (print low byte of `$16`). Other PAL functions and services fault.

The shared assembler accepts `.text`, `.data`, `.org`, `.byte`, `.word` (16 bits), `.long` (32 bits), `.quad` (exact integer literal), `.ascii`, `.asciz`, `.space`, `.equ`, labels, expressions and `.include`. Comments start with `#` or `;`. Native instruction size and alignment are four bytes. Data must be naturally aligned except LDQ_U/STQ_U, which use the containing aligned quadword as Alpha specifies.

## Floating point

IEEE S_floating (single) and T_floating (double) are implemented; VAX F/G/D formats (LDF/LDG/STF/STG and the VAX operates) are not. `$f0`–`$f31` are 64-bit registers (`$f31` reads zero and ignores writes) shown in the register panel's Float tab with the FPCR. Registers hold S values in T layout: LDS widens the exponent per the Alpha memory/register mapping (S denormals keep a zero exponent), STS keeps bits <63:62> and <58:29>, and S operations read their operands back through that mapping. LDT/STT move 64 bits unchanged.

Instructions: LDS/LDT/STS/STT; ADDS/T, SUBS/T, MULS/T, DIVS/T with `/c`, `/m`, `/d` rounding and `/u`, `/su`, `/sui` trap qualifiers; CMPTUN/EQ/LT/LE (and `/su`), writing 2.0 or 0.0; CVTTS, CVTST (`/s`), CVTTQ (`/c /m /d`, `/v /sv /svi`), CVTQS/CVTQT (`/c /m /d`, `/sui`); CPYS/CPYSN/CPYSE with `fmov`, `fneg`, `fabs`, `fclr` and `fnop` aliases; FCMOVxx; FBxx (tests read bits, so -0.0 is zero); MF_FPCR/MT_FPCR. The FIX extension (SQRTS/SQRTT, ITOFS/ITOFT, FTOIS/FTOIT) is always enabled; there are no CPU profiles. CVTLQ/CVTQL are not implemented.

Arithmetic is exact binary rounding in software, so every rounding mode (normal, chopped, minus infinity, and FPCR dynamic including plus infinity) is exact for both formats; no host float rounding is involved. The FPCR models DYN, sticky INV/DZE/OVF/UNF/INE/IOV status with SUM, and the INVD/DZED/OVFD/UNFD/INED/UNDZ disables; DNZ and DNOD are stored but have no effect, and reserved bits read zero. THRAX behaves as if software completion were always available: denormal, infinite and NaN operands give IEEE results instead of hardware traps. Invalid operation, division by zero and overflow trap (an execution fault, before any state change) unless the instruction has `/s` and the matching FPCR disable is set; underflow traps only with `/u`, inexact only with `/i`, integer overflow only with `/v`. Untrapped exceptions set FPCR status. A tiny result without `/u` (or with UNDZ) becomes +0.0. A NaN operand propagates quieted, Fa before Fb (a THRAX choice); invalid operations produce `0x7ff8000000000000`. CVTTQ overflow keeps the low 64 bits and sets IOV and INE. The shared assembler has no float data directives, so constants are written as `.long`/`.quad` bit patterns.

This baseline excludes atomics/locked memory operations, privileged PALcode execution, MMU and virtual address translation, native exception delivery, vector/multimedia extensions, devices and cycle-accurate pipelines. It is not a timing model of a specific EV-series processor. Unsupported native forms produce assembly diagnostics or execution faults.
